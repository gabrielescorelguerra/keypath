::::checkpoint{id="fundamentos" title="O timbre de cada estilo" stage="fundamentos"}

| Estilo                    | Timbres característicos                                |
| ------------------------- | ------------------------------------------------------ |
| Gospel                    | piano, órgão Hammond com Leslie, synth bass            |
| Worship                   | piano, pads longos, plucks com delay                   |
| Neo-soul / R&B            | Rhodes com tremolo ou chorus, Wurlitzer                |
| Funk                      | clavinet (às vezes com wah), Rhodes, órgão, synth bass |
| Pop                       | piano, plucks, pads, leads leves                       |
| Rock alternativo          | piano, órgão com drive, pads escuros, leads de synth   |
| Post-hardcore / metalcore | pads, cordas e coros orquestrais, synths com sidechain |

**Órgão Hammond:** os **drawbars** somam harmônicos (síntese aditiva) — cada um é um tubo virtual. A caixa **Leslie** gira os alto-falantes: lenta (chorale) ou rápida (tremolo).

**Método para copiar um timbre:** família → envelope → brilho → movimento → espaço → região.
