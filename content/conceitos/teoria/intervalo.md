Um **intervalo** é a distância entre duas notas. Ele tem duas partes:

- o **número**, que conta as letras envolvidas, incluindo a primeira e a última. De Dó a Mi há três letras (Dó, Ré, Mi), então é uma **terça**;
- a **qualidade**, dada pelos semitons: maior, menor, justa, aumentada ou diminuta.

| Intervalo     | Semitons | Exemplo a partir de Dó |
| ------------- | -------- | ---------------------- |
| Segunda menor | 1        | Dó → Ré♭               |
| Segunda maior | 2        | Dó → Ré                |
| Terça menor   | 3        | Dó → Mi♭               |
| Terça maior   | 4        | Dó → Mi                |
| Quarta justa  | 5        | Dó → Fá                |
| Quinta justa  | 7        | Dó → Sol               |
| Sexta menor   | 8        | Dó → Lá♭               |
| Sexta maior   | 9        | Dó → Lá                |
| Sétima menor  | 10       | Dó → Si♭               |
| Sétima maior  | 11       | Dó → Si                |
| Oitava justa  | 12       | Dó → Dó                |

:::note{title="Por que o nome importa"}
Ré♯ e Mi♭ são a mesma tecla, mas Dó → Ré♯ é uma **segunda aumentada** e Dó → Mi♭ é uma **terça menor**. O nome do intervalo depende da letra, não só da tecla.
:::
